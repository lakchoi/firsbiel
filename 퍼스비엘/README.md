# 인덕원 퍼스비엘 민간임대 랜딩페이지

민간임대 아파트 상담 신청용 단일 페이지 랜딩페이지입니다.

## 포함 내용

- 상단 네비게이션
- 메인 히어로 섹션
- 장점/특징 섹션
- 평형 안내 섹션
- 상담 절차 섹션
- 상담 신청 폼
- 반응형 레이아웃

## 실행 방법

브라우저에서 [index.html](index.html)을 열면 바로 확인할 수 있습니다.

또는 로컬 서버에서 실행:

```bash
python -m http.server 8000
```

그 다음 브라우저에서 http://localhost:8000 으로 접속합니다.
